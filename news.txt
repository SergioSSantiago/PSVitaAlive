# What's New

## Improvements

- Fixed an issue causing errors during ZIP file extraction (64-bit offsets).
- Improved Homebrew update detection.
- Removed error reporting for insufficient storage or lack of internet connection, as these were generating false positives.

### Tips:
- iTLS-ENSO (full) recommended for HTTPS
- DNS: 8 8 8 8 / 8 8 4 4
- Keep NoNpDrm (and NoPspEmuDrm if you use LiveArea PSP/PS1)

**Enjoy and report issues with session.log when possible. Thank you!**
