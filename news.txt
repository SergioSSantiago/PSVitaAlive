# What's New

## Improvements

- Added OLED/LCD screen protection mode for long downloads, extractions, and installations.
- Fixed crashes caused by repeatedly opening and closing the search keyboard.
- Major image loading, caching, memory usage, and scrolling performance improvements.
- Improved PS Vita PKG installation through BGDL, including better handling of extensionless PKG links.
- Fixed self-update version detection to reliably use GitHub release tags.
- Improved UI responsiveness and Settings performance.
- Additional stability fixes and catalog updates.
