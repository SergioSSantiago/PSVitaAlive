Mascot Generator & Preview

Create PSVitaAlive screen-protection mascots without editing files manually. Import PNG frames, build Idle and Run animations, tune movement parameters, preview the exact 960 × 544 Vita play area, validate the package and export a ready-to-use ZIP.

Local-only tool: images and ZIP files stay in your browser. Nothing is uploaded to PSVitaAlive or any server.

1. Identity

The folder ID is the stable internal identifier. The display name can change later without breaking saved settings.

Lowercase letters, numbers, hyphens and underscores only. This becomes assets/mascots/<id>/.
Name shown in the future PSVitaAlive Settings selector.
Direction the original PNG sprites face. The preview mirrors them automatically when needed.
100 px×100 px
100 × 100 is the logical display area, not a required PNG size. Smaller sprites such as 64 × 64 are kept unchanged and scale up to fill this area without stretching. Larger PNGs are normalized down to fit 100 × 100 while preserving aspect ratio.

2. Behaviour

These values are written to mascot.json and drive the live preview.

px/s
Movement speed in pixels per second.
ms
Run ends when the destination is reached or this timeout expires.
ms

3. Idle animations

Idle animations loop while the mascot stays still. Add as many variants as you want.

4. Run animations

Run animations loop while the mascot travels horizontally or diagonally toward a random destination.

5. Validate & export

The ZIP contains one ready-to-copy mascot folder with mascot.json and all referenced PNG frames.

ZIP layout: <id>/mascot.json + <id>/*.png
