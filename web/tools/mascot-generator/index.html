Mascot Generator & Preview

Create PSVitaAlive screen-protection mascots without editing files manually. Import individual PNG frames or split a transparent Sprite Sheet directly in the browser, build Idle and Run animations, tune movement parameters, preview the exact 960 × 544 Vita play area, validate the package and export a ready-to-use ZIP.

Local-only tool: images, Sprite Sheets and ZIP files stay in your browser. Nothing is uploaded to PSVitaAlive or any server.

4. Idle animations

Idle animations loop while the mascot stays still. Add as many variants as you want.

5. Run animations

Run animations loop while the mascot travels horizontally or diagonally toward a random destination.

6. Validate & export

The ZIP contains one ready-to-copy mascot folder with mascot.json and all referenced PNG frames.
