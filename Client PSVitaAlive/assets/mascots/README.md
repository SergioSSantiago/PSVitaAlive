# Built-in protection mascots

This directory is packaged into the PSVitaAlive VPK as:

```text
app0:mascots/
```

Each built-in mascot lives in its own folder and uses the same package generated by the web **Mascot Generator**:

```text
assets/mascots/<id>/
├── mascot.json
├── idle_*.png
└── run_*.png
```

Do not hard-code mascot names in the client. `MascotManager` discovers folders dynamically from this directory and combines them with user-installed mascots from:

```text
ux0:data/psvitaalive/mascots/
```

`width: 100` and `height: 100` in `mascot.json` describe the logical on-screen mascot box. PNG frames may use smaller or larger physical dimensions; the client preserves aspect ratio and fits the frame inside the logical 100 × 100 area at render time.

See `Client PSVitaAlive/docs/MASCOTS.md` for the complete runtime contract and validation limits.
